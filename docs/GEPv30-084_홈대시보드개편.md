**작성일:** 2026.08.08
**작성자:** 고팀장 (Claude Code)
**Phase:** Phase 2 — S3-c
**지시자:** 노팀장 (개발관리창) — 조대표님 S3-a/S3-b 승인 완료

## 1. 작업 목적
Home.jsx가 선택형(MCQ) 통계만 노출하고 모의고사·통합오답 진입 버튼이 없던 구조적 UX 문제를 해결. 선택형+진위형 통합 대시보드(L1-DB)와 6개 학습 메뉴(L2-A~F)로 전면 교체.

## 2. 수정/추가 파일
| 파일 | 변경 내용 |
|------|----------|
| `src/pages/Home.jsx` | 전면 교체 — 섹터2~5(득점현황/누적풀이/7일학습량/기존 4버튼) 삭제 → L1-DB 통합 대시보드 + L2 메뉴 6개로 대체. 섹터1(헤더)·handleLogout·인증 로직·getSubjectAgg/getAccuracy는 그대로 유지. |

## 3. 주요 변경사항

### 변경 전 (섹터2~5)
```jsx
{/* 섹터2: 득점현황 */}
{/* 섹터3: 누적 풀이 현황 */}
{/* 섹터4: 최근 7일 학습량 */}
{/* 섹터5: 풀이 옵션 — 4개 버튼(회차순/과목별/OX/틀린문제) */}
```

### 변경 후 (L1-DB + L2)
```jsx
{/* L1-DB: 통합 풀이현황 카드(선택형+진위형 합산) + 선택형/진위형 분리 카드 + D-Day 배너 */}
{/* L2 메뉴 6개: A 회차순, B 과목별, C 진위형, D 틀린문제(canUseCounting 조건), E 모의고사(신규), F 통합오답(신규) */}
```

- OX 풀이수는 `attempts WHERE study_mode='ox'` count 쿼리로 신규 로딩 (useEffect, authStatus/userId 변경 시 재조회)
- `mcqTotal`은 기존 `getSubjectAgg()`를 3과목 합산하여 계산
- 목표치는 고정값 사용: MCQ 1,080문제 + OX 3,824문제 = 4,904문제
