## 1. 프로젝트 목적

GEP v3.0은 보험중개사 시험 준비 앱의 파일럿 버전이다. 2026년 9월부터 2개월간 록토코리아 직원 중 보험중개사 시험 응시자를 대상으로 실제 학습 피드백을 수집하고, 2027년 상용 제품 출시를 위한 서비스 품질과 통계 구조를 검증한다.

## 2. 제품 원칙

- 완성형 전체 서비스를 한 번에 공개하지 않는다.
- 기본 문제풀이 서비스를 먼저 열고 실제 사용자 피드백과 학습데이터를 바탕으로 서비스 레벨을 순차적으로 높인다.
- 핵심 가치는 단순 오답노트가 아니라 반복 오답 기반의 정밀 학습통계다.
- 사용자는 오늘의 풀이 수, 과목별 정답률, 누적 정답률, 반복 오답 비율을 통해 현재 위치와 취약점을 자각해야 한다.
- 시험이 임박하면 많이 틀린 문제순, 과목별 반복 오답 중심으로 학습할 수 있어야 한다.
- 통계적 검증 전에는 합격률 또는 합격 가능성을 확정적으로 예측하지 않는다.
