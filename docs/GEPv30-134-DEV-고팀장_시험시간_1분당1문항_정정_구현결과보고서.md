## 1. 배경

GEPv30-132에서 "공고 기준 실제 시험시간"(1교시 60분/2교시 100분)으로 정정했으나, 조대표가 "시간에 혼동이 생겼다"며 재정정 지시. **의도된 원칙은 공고상 실제 배정시간이 아니라 "모의고사는 문제당 1분" 페이싱 규칙**(1교시 법령 40문제→40분, 2교시 손보 80문제→80분) — 실전보다 타이트하게 훈련시키기 위한 의도적 설계. GEPv30-132 이전 원래 값(40분/80분)과 결과적으로 동일하나, 근거가 "구버전 미정정"에서 "1분/문항 원칙 확정"으로 바뀜.

노팀장(선과장 의견 검토) 3관점 사전검토:
- ① 문항당 1분 원칙은 공고 정신과 상충하지 않고 유지보수 관점에서도 타당 → 즉시 반영
- ② 맞춤모의고사 SHORT 모드가 "48문항으로 축소"라는 일부 의견은 오해 소지 — **코드 확인 결과, `customMockService.generateQuestions()`는 timerType과 무관하게 항상 120문항(40+40+40) 고정 생성**. `timerType`은 `customMockConfig.timers[type].part1/part2`로 시간 값만 선택하며 문항 수에는 전혀 관여하지 않음 (`customMockStore.js` `startSession`/`resumeSession`/`submitPart1` 확인). → SHORT는 "시간만 80%" 해석이 맞고, 문항수 축소 아님 확정.
- ③ 간이모의고사도 동일 원칙 적용 시 30문항→30분(기존 40분에서 10분 단축) — 공고 기준 정당.

## 3. 변경하지 않은 것

- **DB 스키마**: 시간 값 변경과 무관, GEPv30-132와 동일 결론.
- **문항 배분/생성 로직**: `generateQuestions()`는 timerType에 관계없이 항상 120문항 고정 — 이번 조사로 재확인.
- **채점 로직**: 시간 값과 무관.
- **breakTime 자체의 20분 값**: GEPv30-132에서 확정된 값 유지(15분→20분 되돌리지 않음). 단 `customMockConfig.js`의 별도 `breakTime` 필드는 이번에 처음 15분→20분으로 동기화(기존 GEPv30-132에서 누락됨).
