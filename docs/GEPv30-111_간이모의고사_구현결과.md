## 3. 지시서 대비 구현 시 발견·수정한 사항 (지시서에 없던 추가 교정)

- **`exams.json`은 순수 배열이 아니라 `{ version, totalCount, rounds, subjects, subSubjects, questions }` 객체.** 지시서 pseudocode의 `exams.filter(...)`를 그대로 쓰면 즉시 크래시. `exams.questions.filter(...)`로 수정.
- **`package.json`에 `"type": "module"`** 설정되어 있어 `.js` 확장자는 ESM으로 해석됨. 지시서의 `require()`/`module.exports` 스타일 스크립트는 `.js`로 저장하면 즉시 오류. 프로젝트 기존 관례(`scripts/*.cjs`)를 따라 `generateMiniMockSets.cjs`로 저장.
- `mini_mock_sets.json` 출력 형식은 GEPv30-109 STEP 2/5-1과 내부 일관성을 맞춰 **세트 배열 그대로**(래핑 객체 없이) 저장.
