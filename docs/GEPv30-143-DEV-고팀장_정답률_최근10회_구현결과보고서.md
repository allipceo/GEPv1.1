# GEPv30-143 정답률 "최근 10회" 표시 구현 결과보고서

**작성일:** 2026-08-20 | **작성자:** 고팀장 (Claude Code) | **선행:** [GEPv30-141](GEPv30-141-DEV-고팀장_통계이어풀기_전체통찰_감사보고서.md) §5 우선순위 2
**브랜치:** `gepv30-138-home-entry-redesign` (미병합)
**기준 결정:** 조대표 확인 — "최근 N회" = 10회

---

## 1. 문제

GEPv30-141 원칙 11번: 정답률은 전체누적과 최근 시도를 구분해야 하는데, 프로젝트 전체에 "최근 N회" 개념이 없었다(`advancedStatsService.js`, `customMockService.js` 모두 누적률만 계산).

## 2. 조사 결과 — 표시 위치 결정

기존 정답률 표시 위치를 먼저 확인했다:
- `StatsPanel.jsx`의 `homeMode` 브랜치(3과목별 정답률)는 **어디서도 렌더링되지 않는 죽은 코드**였다(Home.jsx는 이 컴포넌트를 사용하지 않고 자체 인라인 카드로 통계를 표시함).
- `advancedStatsService.js`(약점 분석)와 `customMockService.js`(맞춤모의고사 약점모드)는 `total_average`/집계 카운트만 입력받아 계산하며, **개별 시도 기록(타임스탬프)이 아예 없는 합성 데이터**를 입력으로 쓰는 경로도 있어(`CustomMockStats.jsx`의 `buildSyntheticAttempts`) 이 경로에는 "최근 N회" 자체를 붙일 수 없다.
- 실사용자가 매번 보는 곳은 **Home.jsx의 선택형/진위형 카드**(`평균 {avgAccuracy}% 정답`, `OX 누적 풀이`)뿐이었다.

→ 가장 방문 빈도가 높고, 원장(`attempts`)에서 직접 조회 가능한 **Home.jsx 두 카드**에 최근10회 정답률을 추가하는 것으로 범위를 정했다(신규 화면 신설 없이 기존 UI 확장).

## 3. 수정 내용

| 파일 | 변경 |
|---|---|
| `src/pages/Home.jsx` | 신규 `useEffect` 추가 — `attempts` 테이블에서 `study_mode != 'ox'`(선택형) / `study_mode = 'ox'`(진위형) 각각 `attempted_at DESC LIMIT 10`으로 조회해 정답률 계산. 선택형 카드는 `누적 {avgAccuracy}% · 최근10회 {N}%`, 진위형 카드는 기존 "OX 누적 풀이" 캡션을 데이터 로드 후 `최근10회 {N}%`로 교체 |

## 4. 설계 참고

- 세부과목별이 아닌 **주요과목(선택형/진위형) 단위**로만 최근10회를 계산했다 — 기존 Home 카드 자체가 세부과목 breakdown 없이 단일 평균만 표시하는 구조라, 이번 추가도 같은 granularity를 유지해 UI 일관성을 지켰다. 세부과목별 최근N회가 필요하면 별도 화면(예: `/stats-dashboard`)에서 논의 필요.
- 쿼리는 로그인 사용자 한정, 각 카드당 1회(limit 10)로 가벼움.

## 4-1. "최근 10회" 기준 명문화 (선과장 검토의견 §2.4 반영, 2026-08-21)

화면마다 "최근 10회 정답률"의 집계 범위가 다르게 오해될 수 있어 명문화한다.

| 위치 | 기준 |
|---|---|
| **Home 전체 카드(선택형/진위형)** | 해당 **유형 전체**(과목 구분 없이)의 최근 10회 시도 기준 — 본 문서가 구현한 범위 |
| 과목/세부과목별 카드(향후 추가 시) | 해당 과목/세부과목 **내**의 최근 10회 시도 기준 — 아직 미구현, 별도 화면 필요 시 이 정의를 따른다 |
| 문제 상세(향후 추가 시) | 해당 문제 1개의 최근 최대 10회 시도 기준 — 아직 미구현 |
| 시도 10회 미만인 경우 | 실제 시도 수 그대로 계산(예: 3회면 3회 기준 %). **2026-08-21 수정 완료** — 라벨을 고정 "최근10회"에서 실제 조회된 행 수 기준 "최근{count}회"로 변경(`Home.jsx`, `recentMcq`/`recentOx` state가 `{accuracy, count}` 반환) |
