# GEPv30-091 모바일 회차목록 로딩 + 재진입 풀이수 캐시 수정

**작성일:** 2026.08.14
**작성자:** 고팀장 (Claude Code)
**Phase:** Phase 5 — 버그 수정
**지시자:** 노팀장 (개발관리창)

---

## 1. 작업 목적

두 가지 버그 수정:
1. 모바일 앱 완전 종료 후 재진입 시 `/service-a` 회차 목록이 빈 화면으로 뜨는 문제 — `questions` 비동기 로딩 완료 전에 `ServiceAHome`이 렌더링되어 발생.
2. 모바일 앱 재진입 시 홈 화면 진위형(OX) 풀이 수가 0으로 초기화되었다가 문제를 한두 개 풀어야 정상 값으로 돌아오는 문제 — `oxTotal`이 Supabase 쿼리 완료 전까지 캐시 없이 무조건 0으로 표시되어 발생.

---

## 2. 수정 파일

| 파일 | 변경 내용 |
|------|----------|
| `src/pages/ServiceAHome.jsx` | `isLoading`/`isReady` 상태 가드 추가 — 로딩 미완료 시 안내 메시지 표시 |
| `src/pages/Home.jsx` | `oxTotal` 초기값을 `localStorage`(`gep_oxTotal:{userId}`) 캐시에서 즉시 복원, DB 조회 완료 시 캐시 갱신 |

```jsx
// 변경 전

```

### Home.jsx

```jsx
// 변경 전
const [oxTotal, setOxTotal] = useState(0)

// 변경 후
const [oxTotal, setOxTotal] = useState(() => {
  try {
    const cached = localStorage.getItem(`gep_oxTotal:${useAuthStore.getState().userId}`)
    return cached ? parseInt(cached, 10) : 0
  } catch { return 0 }
})
```

DB 조회 완료 콜백에 캐시 저장 추가:

```jsx
if (count != null) {
  setOxTotal(count)
  try { localStorage.setItem(`gep_oxTotal:${userId}`, count) } catch {}
}
```
