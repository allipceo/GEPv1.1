# GEPv30-104_일반사용자설정화면

**작성일:** 2026.08.14
**작성자:** 고팀장 (Claude Code)
**Phase:** Phase 6
**지시자:** 노팀장

## 1. 작업 목적

일반 회원(관리자 아님)이 사번/성명 확인, 성명 수정, 비밀번호 변경, 학습 데이터(카운팅 기준) 초기화를 직접 할 수 있는 `/settings` 화면을 신설했다. 홈 화면에는 관리자에게만 보이던 "관리자" 버튼 옆에, 일반 회원에게만 보이는 "설정" 버튼을 추가했다.

## 2. 수정/추가 파일

| 파일 | 변경 내용 |
|------|----------|
| `src/pages/Home.jsx` | `isAdmin` 버튼 블록 바로 아래에 `!isAdmin && authStatus === 'authenticated'` 조건의 "설정" 버튼 추가 (`navigate('/settings')`) |
| `src/pages/Settings.jsx` | 전면 재작성 — 내 계정(사번 read-only·성명 수정·서비스 레벨) / 보안(비밀번호 변경) / 학습 데이터(통계 초기화, 확인 문구 입력 필수) / 앱 정보 4개 섹션 |
| `src/App.jsx` | **(지시서에 없던 필수 추가)** `/settings` 라우트가 아예 등록되어 있지 않아 "설정" 버튼을 눌러도 빈 화면만 뜨는 상태였음. `Settings` import + `<Route path="/settings" element={protectedPage(<Settings />)} />` 추가 |

## 3. 지시서와 실제 코드 간 불일치 — 1건

**`/settings` 라우트 미등록.** `App.jsx`의 `<Routes>`를 확인한 결과 `/settings` 경로가 존재하지 않았다(React Router에 캐치올 라우트도 없어 미매칭 시 완전한 빈 화면). 지시서는 `Home.jsx`/`Settings.jsx` 2개 파일만 명시했지만, 라우트 등록 없이는 이번 기능 자체가 작동하지 않으므로 `App.jsx`에 최소한의 라우트 등록만 추가했다. 다른 회원 전용 페이지(`/mock`, `/ox` 등)와 동일하게 `protectedPage()`(로그인+승인 필요)로 감쌌다.

## 4. 변경 전/후

### Home.jsx
```jsx
{isAdmin && (
  <button onClick={() => navigate('/admin/users')}>관리자</button>
)}
{!isAdmin && authStatus === 'authenticated' && (
  <button onClick={() => navigate('/settings')}>설정</button>
)}
```

### Settings.jsx
지시서 원안 그대로 적용. 단, `useNavigate`/`navigate`는 컴포넌트 내부에서 실제로 사용되지 않아(뒤로가기/홈 이동은 `AppHeader`의 `backTo`/내장 홈 버튼이 처리) 미사용 import를 제거했다. 동작에는 영향 없음.
