# GEPv30-018 서비스A 기출회차순서풀이 구현보고서

- 작성일: 2026-08-05
- 대상: GEP V3.0 1단계 파일럿 서비스 A
- 브랜치: gepv30-phase1-pilot
- 테스트 URL: http://127.0.0.1:5173/

## 1. 구현 목적

서비스 A는 실제 출제되었던 기출문제를 회차별 실제 문항 순서대로 제공하는 파일럿 1단계의 기본 학습 서비스다.

이번 구현의 목표는 다음과 같다.

1. 홈에서 서비스 A 진입점을 명확히 제공한다.
2. 사용자가 회차를 선택할 수 있다.
3. 선택한 회차의 문제를 1번부터 120번까지 실제 순서대로 제공한다.
4. 기존 공통 문제풀이 화면과 카운팅 계약을 재사용한다.
5. 비로그인 또는 미승인 사용자는 서비스 A에 진입하지 못한다.

## 2. 데이터 확인

현재 `public/data/exams.json` 기준 데이터는 다음과 같다.

- 총 문항 수: 1,080문제
- 포함 회차: 23회, 24회, 25회, 26회, 27회, 28회, 29회, 30회, 31회
- 회차별 문항 수: 각 120문제

대표님은 “10년치 기출문제”라고 표현했지만, 현재 파일에는 23~31회까지 9개 회차가 들어 있다. 따라서 이번 서비스 A는 현재 데이터 기준인 23~31회로 구현했다.

23회 데이터에 대해 `partNumber` 1~120 정렬을 확인했고, 1번부터 120번까지 연속성이 확인되었다.

## 3. 주요 변경사항

### 3.1 서비스 A 라우트 추가

- 추가 파일: `src/pages/ServiceAHome.jsx`
- 변경 파일: `src/App.jsx`
- 추가 라우트: `/service-a`

`/service-a`는 `RequireLogin`으로 보호된다. 따라서 로그인하지 않은 사용자는 회차 선택 화면에 접근하지 못하고 등록 요구 화면을 본다.

### 3.2 홈 진입 버튼 추가

- 변경 파일: `src/pages/Home.jsx`

홈 화면에 `기출 회차 순서풀이` 버튼을 추가했다.

- 표시 문구: `기출 회차 순서풀이`
- 범위 표시: `23~31회`
- 클릭 시: `/service-a` 이동

### 3.3 서비스 A 문제 공급 로직

- 변경 파일: `src/stores/examStore.js`

새 상태와 액션을 추가했다.

- `studyMode`
- `startServiceA(round)`
- `startServiceB(subject, subSubject)`
- `setStudyMode(studyMode)`

서비스 A 모드에서는 다음 규칙을 적용한다.

1. `studyMode === 'service_a_sequence'`
2. 선택 회차의 문제만 필터링
3. `partNumber` 오름차순 정렬
4. 진행도 키는 `service_a_{round}` 형식 사용

### 3.4 공통 문제풀이 화면 재사용

- 변경 파일: `src/pages/Question.jsx`

기존 문제풀이 화면을 서비스 A/B 공통 엔진으로 정리했다.

서비스 A에서는 다음처럼 작동한다.

1. 헤더에 `{회차}회 {문항번호}번` 표시
2. 문제 순서는 `partNumber` 기준
3. 답안 제출 시 `studyMode: service_a_sequence`로 기록
4. 기존 `recordAttempt`와 승인 사용자 카운팅 계약 재사용

### 3.5 이어풀기 저장 기준 정리

- 변경 파일: `src/stores/examStore.js`

진행도 저장 조건도 기존 `serviceLevel >= 2`가 아니라 Phase4에서 정의한 승인 사용자 카운팅 계약을 사용하도록 변경했다.

## 5. 레드팀 점검

### 통과한 항목

1. 서비스 A 진입점이 홈에 표시된다.
2. 서비스 A는 로그인/승인 보호 라우트 안에 있다.
3. 회차별 문제는 `partNumber` 기준으로 실제 순서 제공된다.
4. 공통 답안 제출/카운팅 함수를 재사용한다.
5. 이어풀기 키가 서비스 A 회차별로 분리된다.

### 보류 항목

실제 승인 사용자로 다음 항목은 Supabase 연결 후 검증해야 한다.

1. 승인 사용자의 `/service-a` 회차 선택 화면 진입
2. 특정 회차 선택 후 `/question` 이동
3. 1번 문제부터 표시되는지 실제 화면 확인
4. 답안 제출 후 `attempts.study_mode = service_a_sequence` 저장
5. 서비스 A 이어풀기 진행도 저장
