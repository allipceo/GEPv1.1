## 1. 배경 및 목적

멀티 디바이스 학습 환경에서 사용자가 마지막으로 어떤 기기(모바일/PC)로 접속했는지 기록하고,
다른 기기로 접속 시 배너로 안내하는 기능을 추가한다.

**DB 마이그레이션 완료:** 노팀장이 Supabase MCP로 직접 처리 (GEPv30-088 별도 기록)
- `public.users.last_device TEXT` ← 신규 컬럼 ✅
- `public.users.last_access_at TIMESTAMPTZ` ← 신규 컬럼 ✅

## 3. authStore.js 수정 (5곳)

### 수정 1 — defaultProfile에 prevDevice 추가

```javascript
// 변경 전
const defaultProfile = {
  approvalStatus: 'guest',
  realName: null,
  phoneNumber: null,
  resetBaselineAt: null,
  status: 'active',
  isPaused: false,
  approvalMemo: null,
  isAdmin: false,

// 변경 후
const defaultProfile = {
  approvalStatus: 'guest',
  realName: null,
  phoneNumber: null,
  resetBaselineAt: null,
  status: 'active',
  isPaused: false,
  approvalMemo: null,
  isAdmin: false,
  prevDevice: null,  // ← 추가: 이전 접속 기기 (배너 표시용, 로그인 시 갱신)
}
```

### 수정 2 — dismissDeviceBanner 액션 추가

`submitApprovalRequest` 바로 위에 새 액션 삽입:

```javascript
dismissDeviceBanner: () => set({ prevDevice: null }),
```

### 수정 3 — initAuthListener select 쿼리에 last_device 추가

```javascript
// 변경 전 (134~137번째 줄 근처)
const { data, error } = await supabase
  .from('users')
  .select('service_level,status,is_paused,real_name,phone_number,approval_status,approval_memo,reset_baseline_at')
  .eq('user_id', user.id)
  .single()

// 변경 후
const { data, error } = await supabase
  .from('users')
  .select('service_level,status,is_paused,real_name,phone_number,approval_status,approval_memo,reset_baseline_at,last_device')
  .eq('user_id', user.id)
  .single()
```

> ⚠️ refreshProfile 함수(68~93번째 줄)의 select는 수정하지 않는다. initAuthListener의 select만 수정.

### 수정 4 — 로그인 성공 블록: setAuth 직후 채널 기록 추가

`get().setAuth(...)` 호출 직후(179번째 줄 직후)에 삽입:

```javascript
// S4: 접속 채널 감지 및 DB 기록 (fire-and-forget)
const currentDevice = window.innerWidth < 768 ? 'mobile' : 'desktop'
set({ prevDevice: profileData?.last_device ?? null })  // 이전 기기를 state에 보관
supabase
  .from('users')
  .update({ last_device: currentDevice, last_access_at: new Date().toISOString() })
  .eq('user_id', user.id)
  .then(({ error: devErr }) => {
    if (devErr) console.warn('[GEP] last_device update failed:', devErr.message)
  })
```

> **핵심 로직:** `prevDevice`에 DB의 이전 기기를 저장해두고, 현재 기기로 DB를 업데이트.
> Home.jsx에서 `prevDevice !== currentDevice`이면 배너 표시.

### 수정 5 — persist partialize 추가 (prevDevice를 localStorage에서 제외)

```javascript
// 변경 전 (파일 마지막 줄)
    { name: 'gep_auth_v1' }
  )
)

// 변경 후
    { 
      name: 'gep_auth_v1',
      partialize: ({ prevDevice, ...rest }) => rest,  // prevDevice는 메모리에만 유지
    }
  )
)
```

> **이유:** prevDevice는 로그인 이벤트 시마다 새로 계산해야 하므로 localStorage에 남기면 안 됨.
> 앱 재로드 시 항상 null로 초기화되어야 배너가 오작동하지 않음.

## 4. Home.jsx 수정 (3곳)

### 수정 1 — authStore에서 추가 state 읽기

기존 `const isAdmin = useAuthStore((s) => s.isAdmin)` 바로 아래에 추가:

```javascript
const prevDevice = useAuthStore((s) => s.prevDevice)
const dismissDeviceBanner = useAuthStore((s) => s.dismissDeviceBanner)
```

### 수정 2 — 배너 표시 조건 계산

`const dDay = calcDday()` 바로 아래에 추가:

```javascript
// S4: 기기 전환 감지 배너 표시 여부
const currentDevice = window.innerWidth < 768 ? 'mobile' : 'desktop'
const showDeviceBanner = prevDevice !== null && prevDevice !== currentDevice
```

### 수정 3 — 배너 JSX 추가

authenticated 상태의 return문 최상단 div의 첫 번째 자식으로 삽입.
(현재 코드에서 `{/* 섹터1: 헤더 */}` 또는 첫 번째 헤더 div 바로 위에 삽입)

```jsx
{/* S4: 기기 전환 감지 배너 */}
{showDeviceBanner && (
  <div className="bg-amber-50 border-b border-amber-200 px-4 py-2 flex items-start gap-2">
    <span className="text-base mt-0.5 flex-shrink-0">
      {prevDevice === 'mobile' ? '📱' : '💻'}
    </span>
    <div className="flex-1 min-w-0">
      <p className="text-xs font-semibold text-amber-800">
        {prevDevice === 'mobile' ? '모바일' : 'PC'}에서 학습 중이었습니다
      </p>
      <p className="text-xs text-amber-600">
        이어서 학습하려면 {prevDevice === 'mobile' ? '모바일' : 'PC'}에서 접속하세요
      </p>
    </div>
    <button
      onClick={dismissDeviceBanner}
      className="text-amber-400 hover:text-amber-600 text-sm font-bold flex-shrink-0 mt-0.5 leading-none"
      aria-label="배너 닫기"
    >
      ✕
    </button>
  </div>
)}
```

## 5. 검증 기준

| 코드 | 항목 | 합격 기준 |
|------|------|----------|
| V1 | 빌드 | `npm run build` 에러 없음 |
| V2 | DB 기록 | 로그인 후 Supabase users 테이블에서 last_device, last_access_at 값이 채워지는지 SQL 확인 |
| V3 | 배너 표시 | PC 로그인 후 모바일로 접속 시 "💻 PC에서 학습 중이었습니다" 배너 표시 |
| V4 | 배너 닫기 | ✕ 버튼 클릭 시 배너 사라짐 |
