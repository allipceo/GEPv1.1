## 1. 작업 목적

멀티 디바이스 학습 환경에서 사용자가 마지막으로 어떤 기기(모바일/PC)로 접속했는지 기록하고,
다른 기기로 접속 시 홈 화면에 배너로 안내하는 기능 추가.

## 3. 주요 변경사항

### authStore.js — 변경 전/후

#### 수정 1: defaultProfile에 prevDevice 추가
```javascript
// 변경 후
const defaultProfile = {
  ...
  isAdmin: false,
  prevDevice: null,  // S4: 이전 접속 기기 (배너 표시용, 로그인 시 갱신)
}
```

#### 수정 2: dismissDeviceBanner 액션 추가
```javascript
dismissDeviceBanner: () => set({ prevDevice: null }),
```

#### 수정 3: select 쿼리에 last_device 추가
```javascript
// 변경 후 (initAuthListener 내부)
.select('service_level,...,last_device')
```

#### 수정 4: 로그인 성공 시 채널 감지 + DB 기록 (setAuth 직후)
```javascript
// S4: 접속 채널 감지 및 DB 기록 (fire-and-forget)
const currentDevice = window.innerWidth < 768 ? 'mobile' : 'desktop'
set({ prevDevice: profileData?.last_device ?? null })
supabase.from('users').update({ last_device: currentDevice, last_access_at: new Date().toISOString() })
  .eq('user_id', user.id)
  .then(({ error: devErr }) => {
    if (devErr) console.warn('[GEP] last_device update failed:', devErr.message)
  })
```

#### 수정 5: persist partialize (prevDevice localStorage 제외)
```javascript
{
  name: 'gep_auth_v1',
  partialize: ({ prevDevice, ...rest }) => rest,
}
```

### Home.jsx — 기기 전환 배너

```jsx
{showDeviceBanner && (
  <div className="bg-amber-50 border border-amber-200 rounded-xl px-4 py-2 flex items-start gap-2">

      {prevDevice === 'mobile' ? '📱' : '💻'}
    </span>
    <div className="flex-1 min-w-0">
      <p className="text-xs font-semibold text-amber-800">
        {prevDevice === 'mobile' ? '모바일' : 'PC'}에서 학습 중이었습니다
      </p>
      <p className="text-xs text-amber-600">
        이어서 학습하려면 {prevDevice === 'mobile' ? '모바일' : 'PC'}에서 접속하세요
      </p>
    </div>
    <button onClick={dismissDeviceBanner} ...>✕</button>
  </div>
)}
```
