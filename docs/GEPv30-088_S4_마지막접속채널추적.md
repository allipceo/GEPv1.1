## 1. 작업 목적

멀티 디바이스 학습 환경에서 사용자의 마지막 접속 기기(모바일/PC)를 추적하여,
다른 기기로 접속 시 홈 화면에 기기 전환 알림 배너를 표시하는 S4 기능 구현.

## 2. 수정/추가 파일

| 파일 | 변경 내용 |

| src/stores/authStore.js | prevDevice state + dismissDeviceBanner 액션 + 로그인 시 채널 기록 + partialize |

| docs/GEPv30-088-S4-마지막접속채널추적_개발지시서.md | 노팀장 작성 지시서 참조용 |

- public.users.last_device TEXT 신규 컬럼
- public.users.last_access_at TIMESTAMPTZ 신규 컬럼

---

## 3. 주요 변경사항

### authStore.js 5곳 수정

1. defaultProfile에 prevDevice: null 추가 (S4 이전 접속 기기 보관)
2. dismissDeviceBanner 액션 추가 → set({ prevDevice: null })
3. initAuthListener select 쿼리에 last_device 추가
4. 로그인 성공 후 setAuth 직후 채널 감지 + DB 업데이트 (fire-and-forget)
5. persist partialize 추가 → prevDevice를 localStorage 저장에서 제외

### Home.jsx 3곳 수정

1. prevDevice, dismissDeviceBanner authStore에서 읽기 추가
2. showDeviceBanner 계산: prevDevice !== null && prevDevice !== currentDevice
3. 기기 전환 배너 JSX 추가 (authenticated return문 최상단, 조건부 표시)
