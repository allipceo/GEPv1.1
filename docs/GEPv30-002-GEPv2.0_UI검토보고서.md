# GEPv30-002 GEP V2.0 UI 검토보고서

## 1. 검토 개요

검토 대상은 현재 배포되어 모바일과 웹에서 작동 중인 GEP V2.0 앱이다.

- 배포 URL: https://gepv11.vercel.app/
- 검토일: 2026년 8월 4일
- 검토 관점: 홈 UI, 모바일 반응형, OX 학습, 객관식 기출 학습, 모의고사, 맞춤 모의고사

이번 검토의 핵심 결론은 다음과 같다.

**GEP V2.0은 이미 완성된 작동 앱이며, V3.0은 새로 기획하는 앱이 아니라 V2.0의 작동 UI와 데이터 흐름을 계승, 정리, 고도화하는 프로젝트로 정의해야 한다.**

## 2. 확인한 주요 화면

### 2.1 홈 화면

홈 화면에서 확인한 주요 요소는 다음과 같다.

1. `GEP 보험중개사` 앱 타이틀
2. 시험일 설정
3. Google 로그인
4. 설정 버튼
5. 무료체험 현황
6. 과목당 30문제 무료
7. 전체 진행률
8. 법령, 손보1부, 손보2부 진행률
9. OX 진위형 문제 풀기
10. 통합 틀린문제 복습
11. 모의고사
12. 맞춤 모의고사
13. 과목 선택

평가:

1. 모바일 앱형 홈 구조가 명확하다.
2. 무료체험 현황과 핵심 학습 메뉴가 첫 화면에 모여 있어 진입 장벽이 낮다.
3. OX, 틀린문제, 모의고사, 맞춤 모의고사가 이미 고급 서비스 축으로 구현되어 있다.
4. 웹 화면에서는 모바일 폭 컨테이너를 중앙에 배치하여 앱 사용감을 유지한다.

개선 후보:

1. 모바일 첫 화면에서 마지막 과목 버튼이 하단에 걸릴 수 있다.
2. 헤더의 Google 로그인, 설정, 제목 영역이 작은 화면에서는 다소 촘촘하다.
3. 홈의 여러 기능이 모두 비슷한 위계로 보여, 무료 사용자에게 가장 먼저 눌러야 할 기본 학습 경로를 조금 더 분명하게 만들 여지가 있다.

## 3. 모바일 반응형 검토

모바일 폭 390px 기준으로 확인한 결과는 다음과 같다.

1. 가로 스크롤은 발생하지 않았다.
2. 주요 버튼 폭은 약 340px 수준으로 충분하다.
3. 주요 터치 버튼 높이는 44px 이상으로 대체로 적절하다.
4. 홈 전체 높이는 약 890px로, 첫 화면에서 대부분의 핵심 기능이 보인다.

평가:

모바일 대응은 전반적으로 양호하다. 현재 앱은 데스크톱 웹보다는 모바일 사용을 우선한 설계로 보이며, 보험중개사 수험생이 이동 중 반복 학습하기에 적합한 방향이다.

개선 후보:

1. 제목이 두 줄로 접히는 화면에서 로그인 버튼과 설정 버튼의 시각적 간격을 조금 더 안정화한다.
2. 하단 과목 리스트는 첫 화면 노출보다 학습 시작 우선순위를 고려해 배치를 재검토할 수 있다.

## 4. OX 진위형 학습 UI

### 4.1 과목 선택

OX 진위형 문제 풀기 진입 시 다음 구조가 확인되었다.

1. 법령
2. 손보1부
3. 손보2부
4. 각 과목별 Round 1 및 누적 문항 표시

법령 진입 후에는 다음 세부 과목 구조가 확인되었다.

1. 전체 4과목 통합
2. 보험업법
3. 상법 보험편
4. 위험관리론
5. 세제 및 재무설계

평가:

대분류와 세부과목 구조가 이미 UI에 반영되어 있다. V3.0의 데이터 설계에서는 `LAYER1`, `LAYER2`, `EROUND`, `QCODE`를 명확하게 계승해야 한다.

### 4.2 OX 문제풀이 화면

확인한 구성은 다음과 같다.

1. 과목 선택으로 돌아가기
2. Round 진행률
3. 누적 풀이 수
4. 회차, 과목, 문제 번호 출처
5. 문제 본문
6. O / X 버튼
7. 이전
8. 건너뛰기
9. 정답 제출 후 피드백
10. 다음 버튼

평가:

기본 학습 흐름은 정상적으로 구성되어 있다. 답안 선택 후 진행률이 갱신되고, 정답 여부 피드백도 표시된다.

개선 후보:

1. 짧은 문제에서도 본문과 O/X 버튼 사이에 빈 공간이 크게 생긴다.
2. O/X 버튼이 화면 하단에 고정되어 있어 문제 확인 후 답안 선택까지 시선 이동이 길다.
3. 오답 시 정답 버튼이 너무 흐린 회색으로 보여 정답 강조가 약하다.
4. 문제 본문이 긴 경우와 짧은 경우 모두 안정적인 버튼 위치 정책이 필요하다.

V3.0 권고:

OX 문제풀이 화면은 본문 직후 답안 버튼을 배치하는 방식과 하단 고정 답안바 방식을 비교 검토한다. 수험생의 반복 학습 리듬을 고려하면, 짧은 문제에서는 본문 직후 답안 버튼이 더 빠른 피드백을 제공할 수 있다.

## 5. 객관식 기출 학습 UI

홈의 과목 선택에서 법령을 누르면 아코디언 방식으로 세부 과목이 펼쳐진다.

확인한 세부 과목 예시는 다음과 같다.

1. 보험업법
2. 상법
3. 세제재무
4. 위험관리

보험업법 진입 후 확인한 구성은 다음과 같다.

1. 홈으로
2. 현재 학습 범위: 전체 보험업법
3. 진행률: 1/90
4. 과목변경
5. 회차, 대분류, 세부과목
6. 객관식 문제 본문
7. 1번부터 4번까지 선택지
8. 세부과목 누적 현황
9. 금일 현황
10. 이전, 다음

평가:

V3.0에서 핵심으로 삼아야 할 기출 객관식 학습 흐름이 이미 구현되어 있다. 특히 `누적`과 `금일현황`이 문제풀이 화면에 포함된 점은 수험생에게 즉각적인 학습 피드백을 준다.

개선 후보:

1. 보기 텍스트가 긴 경우 선택지 버튼과 본문 가독성의 균형을 계속 점검해야 한다.
2. 정답 제출 전후의 버튼 상태와 해설 표시 방식은 V3.0에서 표준화할 필요가 있다.
3. 과목변경, 홈, 이전, 다음의 네비게이션 우선순위를 더 명확히 할 수 있다.

## 6. 모의고사 UI

모의고사 화면에서 확인한 구성은 다음과 같다.

1. 시험 구조 안내
2. 1교시 법령 40문제 40분
3. 2교시 손보 80문제 80분
4. 합격 기준: 과목당 40점 이상, 전체 평균 60점 이상
5. 23회부터 31회까지 회차 선택
6. 회차별 미응시 상태
7. 시작하기 버튼
8. 통계 진입

평가:

시험 구조를 먼저 보여주는 구성이 매우 좋다. 사용자가 단순히 문제를 푸는 것이 아니라 실제 시험 단위로 훈련한다는 맥락을 즉시 이해할 수 있다.

중요 수정 사항:

기존 V3.0 초안에는 보유 기출 범위를 20회부터 30회까지로 표현했으나, 배포 앱 UI에는 23회부터 31회까지 모의고사 회차가 표시된다. V3.0 기획에서는 실제 데이터 범위와 서비스 표시 범위를 다시 확정해야 한다.

## 7. 맞춤 모의고사 UI

맞춤 모의고사 화면에서 확인한 구성은 다음과 같다.

1. 맞춤 모의고사 구조
2. 법령 40문제, 손보 80문제, 총 120문제
3. 합격 기준 안내
4. 표준 모드
5. 1,080개 풀에서 과목별 균등 랜덤 추출
6. 약점 집중 모드
7. 정답률 하위 3개 세부과목 비중 2배 집중 훈련
8. 최소 10회 풀이 후 사용 가능
9. 실제 시험 시간
10. 단축 모드 80%
11. 생성하기
12. 최근 응시 기록

평가:

맞춤 모의고사는 이미 고급 서비스 상품 가치가 뚜렷하다. 특히 약점 집중 모드는 V3.0의 핵심 차별화 기능으로 유지해야 한다.

개선 후보:

1. 약점 집중 모드가 비활성화된 이유는 표시되지만, 활성화 조건까지의 진행 상태를 함께 보여주면 더 좋다.
2. 표준 모드의 `1,080개 풀`이 어떤 데이터 기준인지 운영 문서에 명시해야 한다.
3. 생성하기 후 문제 구성 알고리즘과 결과 저장 구조를 V3.0 데이터 문서에 포함해야 한다.

## 9. V3.0 기획에 반영할 사항

### 9.1 전제 수정

기존 표현:

V3.0은 보험중개사 시험 V3.0을 새로 기획한다.

수정 방향:

V3.0은 이미 모바일과 웹에서 작동하는 GEP V2.0 완성 앱을 기준으로, UI/UX, 데이터 구조, 운영 도구, 서비스 상품 구조를 정리하고 고도화한다.

### 9.2 반드시 계승할 V2.0 자산

1. 모바일 앱형 홈 구조
2. 무료체험 현황
3. 과목당 무료 문제 제공 구조
4. OX 진위형 학습
5. 객관식 기출 학습
6. 통합 틀린문제 복습
7. 회차별 모의고사
8. 맞춤 모의고사
9. 약점 집중 모드
10. 실제 시험 구조 기반 모의고사
11. 금일/누적 현황
12. Google 로그인

### 9.3 V3.0 개선 핵심

1. 현재 작동 UI를 기준으로 화면 명세서를 작성한다.
2. 현재 실제 데이터 범위를 확정한다.
3. 문제풀이 화면의 답안 버튼 위치와 피드백 강도를 개선한다.
4. OX, 객관식, 모의고사, 틀린문제의 통계 기준을 통합한다.
5. 맞춤 모의고사와 약점 집중 모드의 알고리즘을 문서화한다.
6. 운영자가 신규 회차를 추가할 수 있는 데이터 관리 도구를 만든다.

## 10. 결론

GEP V2.0은 이미 모바일과 웹에서 작동하는 완성 앱이다. 홈, OX 학습, 객관식 기출, 모의고사, 맞춤 모의고사까지 핵심 학습 기능이 구현되어 있다.

따라서 GEP V3.0의 올바른 방향은 새로 만드는 것이 아니라, 다음 세 가지다.

1. V2.0의 작동 UI와 사용자 흐름을 표준 명세로 정리한다.
2. 데이터와 통계 구조를 중앙화하여 안정성을 높인다.
3. 문제풀이 경험의 작은 마찰을 줄이고, 고급 서비스의 상품 가치를 더 선명하게 만든다.

최종 권고:

**V3.0은 V2.0 완성 앱을 리빌드하는 프로젝트가 아니라, V2.0을 기준으로 서비스 운영성과 학습 효과를 높이는 고도화 프로젝트로 정의한다.**
