# GEPv30-166 로그인 화면 아이디 문구 및 관리자 연락처 수정 결과보고서

작성일: 2026-10-05
작성자: 고팀장(Codex)
상태: 구현 완료

## 1. 요청

최초 로그인 화면에서 기존 `사번` 입력 안내를 `아이디`로 바꾸고, 하단 안내문을 신규 가입자가 관리자에게 연락하도록 변경한다. 관리자 연락처는 `choeunsang@gmail.com`으로 표시한다.

조대표님 요청에 따라 전체 프로그램에 나쁜 영향을 주지 않는 방식으로 처리한다.

## 2. 구현 원칙

이번 작업은 화면 문구와 입력 UI만 수정했다.

변경하지 않은 항목:

- Supabase 인증 방식
- 내부 변수명 `employeeId`
- 로그인 이메일 생성 규칙 `아이디 + @gep.local`
- 비밀번호 검증 기준
- 관리자 신규회원 생성 로직
- 사용자 승인/카운팅/통계 로직
- DB 스키마

따라서 기존 계정과 관리자 화면의 동작 계약은 유지된다.

## 3. 변경 파일

| 파일 | 변경 내용 |
|---|---|
| `src/components/LoginButton.jsx` | 로그인 화면 라벨 `사번` → `아이디`, 오류 문구 `사번 또는 비밀번호` → `아이디 또는 비밀번호`, 비밀번호 입력창의 `010-` 접두 UI 제거, 신규 가입자 관리자 연락처 표시 |

## 4. 세부 변경

### 4.1 아이디 라벨 변경

화면 표시 라벨을 다음과 같이 변경했다.

- 변경 전: `사번`
- 변경 후: `아이디`

검증 문구도 다음과 같이 변경했다.

- 변경 전: `사번은 숫자 6자리 이상이어야 합니다.`
- 변경 후: `아이디는 숫자 6자리 이상이어야 합니다.`

로그인 실패 문구도 다음과 같이 변경했다.

- 변경 전: `사번 또는 비밀번호가 올바르지 않습니다.`
- 변경 후: `아이디 또는 비밀번호가 올바르지 않습니다.`

### 4.2 비밀번호 입력 UI 정리

기존 화면에는 비밀번호 앞에 `010-` 접두 UI가 표시되어 휴대폰 번호처럼 보이는 문제가 있었다.

이를 제거하고 일반 비밀번호 입력창으로 변경했다.

단, 기존 파일럿 운영 계약상 비밀번호 8자리 기준은 유지했다.

### 4.3 신규 가입자 안내 추가

하단 안내문을 다음과 같이 변경했다.

```text
신규 가입자는 관리자에게 연락하세요
choeunsang@gmail.com
```

이메일은 `mailto:` 링크로 표시했다.

## 5. 영향 검토

이번 변경은 UI 표시 문구 변경이다. 내부 인증 계약은 유지된다.

| 영역 | 영향 |
|---|---|
| 기존 사용자 로그인 | 영향 없음 |
| 관리자 신규회원 생성 | 영향 없음 |
| Supabase Auth | 영향 없음 |
| users 테이블 | 영향 없음 |
| 승인/카운팅/통계 | 영향 없음 |
| 비밀번호 초기화 | 영향 없음 |

주의할 점:

- 화면에는 `아이디`라고 표시되지만, 내부적으로는 기존 `employeeId` 값을 그대로 사용한다.
- 현재 아이디는 숫자 6자리 이상 형식을 유지한다.
- 향후 `20260Bxxx`처럼 영문이 섞인 아이디를 공식 허용하려면 별도 지시서로 검증식과 관리자 생성 로직을 함께 바꿔야 한다.
