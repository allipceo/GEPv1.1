# GEPv30-103_모의고사_통계이중기록_재응시버튼

**작성일:** 2026.08.14
**작성자:** 고팀장 (Claude Code)
**Phase:** Phase 6 (통계 통합)
**지시자:** 노팀장

## 1. 작업 목적

GEPv30-103 사전 조사에서 확인된 대로, 모의고사 풀이 결과가 `mock_exam_sessions`/`mock_exam_attempts` 전용 테이블에만 기록되고 일반 통계(`attempts`/`question_stats`, Home 화면 카운터·WrongReview·StatsDashboard 반복오답 등)에는 전혀 반영되지 않던 문제를 해결했다. 또한 재응시 진입점이 `MockExamResult.jsx`에만 있고 `MockExamHome.jsx` 완료 카드에는 없던 점을 보완했다.

## 2. 수정 파일

| 파일 | 변경 내용 |
|------|----------|
| `src/pages/MockExamQuiz.jsx` | `recordAttempt`(statsService) + `useStatsStore` import 추가. `handleSubmit()`의 Supabase 저장 블록(회원 한정) 안에서 `questions` 전체를 순회하며 `recordAttempt(..., studyMode: 'mock_exam')`을 fire-and-forget으로 호출 |
| `src/pages/MockExamHome.jsx` | `RESULT_LS_KEY` import 추가. `RoundCard`의 `state === 'done'` 버튼 블록을 "성적표 보기" + "재응시" 2버튼 구조로 교체. "재응시"는 4개 localStorage 키(진행/결과 × part1/part2) 삭제 후 `/mock/${round}/part1`로 이동 |

## 3. 변경 전/후

### MockExamQuiz.jsx — handleSubmit() 저장 블록
```jsx
// 변경 후 (기존 saveSession/saveAttempts 호출 뒤에 추가)
const authState = useAuthStore.getState()
questions.forEach((q, idx) => {
  const questionNum = idx + 1
  const selected = answers[questionNum] ?? null
  recordAttempt(useStatsStore.getState(), authState, {
    question: q,
    selectedAnswer: selected,
    isCorrect: selected != null && Number(selected) === Number(q.answer),
    studyMode: 'mock_exam',
  })
})
```

### MockExamHome.jsx — RoundCard 완료 버튼
```jsx
{state === 'done' && (
  <div className="flex flex-col gap-2">
    <button onClick={() => navigate(`/mock/${round}/result`)}>성적표 보기</button>
    <button onClick={() => { /* localStorage 4키 삭제 */ navigate(`/mock/${round}/part1`) }}>
      재응시
    </button>
  </div>
)}
```

## 4. 동작 확인 사항

- `recordAttempt`는 내부적으로 `canCountAttempts(authState)` 게이트를 통과해야 기록되고, 통과 시 `attempts` insert + `statsStore.updateStats()` + `upsert_question_stat` RPC까지 기존 서비스A/B와 동일한 경로로 실행된다(코드 재사용, 신규 로직 없음).
- `mockExamSupabase.saveSession()`/`saveAttempts()` 호출은 그대로 유지 — `mock_exam_sessions`/`mock_exam_attempts` 축(회차별 응시 기록·attempt_number)은 변경하지 않았다.
- `MockExamHome`의 "재응시"가 지우는 4개 키는 `MockExamResult.jsx`의 기존 `handleRetry()`와 동일한 키 세트(`PROGRESS_LS_KEY`/`RESULT_LS_KEY` × part1/part2)라 두 진입점의 동작이 일치한다.
