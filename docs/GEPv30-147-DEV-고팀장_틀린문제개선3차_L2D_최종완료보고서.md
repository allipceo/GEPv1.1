## 1. 배경 — 왜 두 트랙으로 나뉘었나

이 세션은 원래 "틀린문제 풀기 고도화"(GEPv30-138, 홈 L2-D 진입점 재설계) 하나로 시작했다. 구현 도중 발견된 5개 결함(D4~D9, GEPv30-139 §9~12에 상세)을 고치던 중 조대표가 "코드가 누더기 걸레가 되고 있다"는 우려를 제기했고, 그 결과 통계·이어풀기 전체 철학을 먼저 정리하고 전 서비스를 통찰 감사하는 별도 작업(GEPv30-141~146)이 끼어들었다. 이 문서는 원래 트랙이었던 GEPv30-138(L2-D)로 돌아와 마무리를 짓는다.

## 2. GEPv30-138(L2-D) 자체 범위 — 완료 상태

| STEP | 내용 | 상태 |
|---|---|---|
| 1~7 | 화면 흐름 구현(세부과목→유형→정확한횟수→출제), 브랜치 격리, 빌드 검증 | ✅ (GEPv30-139 §1) |
| 추가1 | `ChallengeResult.jsx` L2-D 컨텍스트 보존(l2dContext) | ✅ (GEPv30-139 §9) |
| 추가2 | OX 재도전 시 subject 누락 기록 수정 + 9건 백필 | ✅ (GEPv30-139 §10) |
| 추가3 | OX 문제 본문 미표시 수정 | ✅ (GEPv30-139 §11) |
| 추가4 | OX 일반풀기 이어풀기 죽은 코드 연결 | ✅ (GEPv30-139 §12, 이후 GEPv30-142에서 ID 앵커 방식으로 재차 보강) |
| 8 | 실계정 로그인 → 전체 흐름 클릭 검증 | ⏸ 조대표 담당 — 고팀장은 로그인 자격증명을 다룰 수 없음 |

**GEPv30-138 자체 코딩 범위는 모두 완료되어 있었다.** 이후 진행된 통계 통찰 감사(GEPv30-141~146)는 별도 트랙(OX 일반풀기·Home 정답률·통합오답복습·미니/맞춤모의고사)이며, 그 결과물이 GEPv30-138이 만든 파일(`ChallengeMode.jsx`, `oxStore.js`, `oxService.js`, `OXSubject.jsx`)을 다시 건드렸다.

## 3. 레이어링 이후 회귀 여부 재확인 (오늘 재검증)

통계 통찰 트랙(GEPv30-142~145)이 L2-D가 의존하는 파일들을 다시 수정했으므로, L2-D 흐름이 여전히 정상 동작하는지 오늘 다시 확인했다.

| 라우트 | 확인 내용 | 결과 |
|---|---|---|
| `/wrong-review/subjects` | 비로그인 리다이렉트, 콘솔 에러 | ✅ 정상, 신규 에러 없음 |
| `/wrong-review/type/상법` | 동일 | ✅ 정상 |
| `/wrong-review/count/상법/OX` | 동일 | ✅ 정상 |
| `/unified-wrong/challenge/1` | 동일(GEPv30-144 검증 시 이미 확인) | ✅ 정상 |

`ChallengeMode.jsx`에 레이어링된 두 변경(GEPv30-144의 `bypassCache:true` 전환, 그리고 GEPv30-138 자체의 sourceFilter/exactCount 필터 확장)은 서로 다른 관심사(무엇을 조회하는가 vs 어떻게 필터링하는가)라 충돌하지 않는다 — `bypassCache`는 `fetchAllWrongQuestions` 호출 방식만 바꿨고, L2-D의 3중 필터 체인(§GEPv30-139 §3)은 그 결과 위에서 그대로 동작한다.

## 4. 실제로 남은 것

1. **실계정 로그인 전체 흐름 클릭검증** — 홈 → "틀린 문제 풀기" → 세부과목 선택 → 유형(진위형/선택형) 선택 → 정확한 틀린횟수 선택 → 출제 → 오답 시 다음 조회에서 횟수+1 반영까지, 조대표 본인 브라우저에서 한 번 끝까지 확인.
2. **브랜치 병합 승인** — `gepv30-136-unified-wrong` → `gepv30-138-home-entry-redesign` → `main` 순서로 병합(CLAUDE.md 정책상 병합은 조대표 승인 필요, 고팀장이 임의로 진행하지 않음).
3. 병합 후 Vercel 자동 배포 확인 (고팀장 담당).

## 5. 결론

GEPv30-138(틀린문제 풀기 고도화, L2-D 홈 진입점 재설계)은 **코딩·빌드·비로그인 스모크 검증까지 완료된 상태**이며, 이후 진행된 통계 통찰 트랙의 변경사항과도 회귀 없이 공존함을 오늘 재확인했다. 남은 것은 조대표의 실계정 클릭검증과 병합 승인뿐이다.
